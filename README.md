# Video Batch AI — Web Prototype

موقع واجهة أولية متجاوبة باسم Video Batch AI.

## التشغيل
افتح index.html في المتصفح.

## الموجود
- صفحة رئيسية عربية RTL
- هوية بصرية متناسقة
- قسم مميزات
- مساحة عمل
- اختيار عدة فيديوهات حتى 25
- قائمة مهام ونسب تقدم
- إعدادات لغة
- محاكاة المعالجة في الخلفية

## للإنتاج
لتحويله إلى خدمة حقيقية نحتاج Backend لمعالجة الفيديو:
- رفع ملفات قابل للاستئناف
- طابور مهام
- Speech-to-Text
- ترجمة
- SRT/VTT
- FFmpeg
- دبلجة صوتية
- تخزين سحابي
- إشعارات Web Push
- معالجة متوازية للفيديوهات الطويلة
